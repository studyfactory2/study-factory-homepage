# Study Factory Homepage

Premium homepage for 자격증공장 and Study Factory Research Lab.

## Commands

```bash
yarn install
yarn dev
yarn lint
yarn build
```

## Architecture

- Next.js Pages Router
- MUI for structure, controls, icons, and reusable styled primitives
- SCSS for page-level visual design
- Separate `pc` and `mobile` component/style folders
- Korean-first copy with English-ready i18n
